# Task 20260706-1200: Fix DATABASE_URL env var resolution

## Problem
User gets `DATABASE_URL environment variable is not set` error. `DATABASE_URL` is correctly set in root `.env`, but `prisma.config.ts` at root does `import "dotenv/config"` and `dotenv` is only declared in sub-packages (`apps/web`, `packages/auth`), not in root `package.json`. pnpm strict mode blocks resolution.

## Fix
Add `dotenv: "17.4.2"` to root `devDependencies` in `package.json`.

## Result
✅ `dotenv` added to root `devDependencies`
✅ `pnpm install` succeeded (postinstall `prisma generate` also succeeded)
✅ `pnpm --filter @recetario/db exec prisma generate` no longer fails with DATABASE_URL error

## File Changed
- `package.json` — added `"dotenv": "17.4.2"` to `devDependencies`
