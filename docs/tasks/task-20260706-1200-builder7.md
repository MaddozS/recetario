## Context Received
- **Root cause**: `.env` is at repo root (`/Users/maddozs/personal-projects/recetario/.env`). Astro's Vite module runner doesn't load `.env` into `process.env`. Packages use `process.env.X` (not `import.meta.env.X`), so they never see the vars.
