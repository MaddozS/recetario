# nuxt
- Feature components under `app/features/**` are NOT auto-imported (only the shared UI kit under `~/components/ui` and landing are): every feature component must be imported explicitly. A missing import silently renders nothing and `nuxt typecheck` does not catch it — the component tests do. Confidence: 0.6
- With `useAsyncData("<key>")` a fixed key caches its payload while status is `success`, so it does NOT refetch when navigating back to the page, and a query-only navigation does not remount the page (`<NuxtPage>`'s key is the interpolated path). Consequence: client-side reducers must mutate the cached snapshot BEFORE navigating away (e.g. create/duplicate: POST → reducer → `navigateTo`), and any other slice that changes the same data must invalidate it with `refreshNuxtData("<key>")` afterwards. Confidence: 0.6
- Shareable list filters live in the route query (e.g. `?category=`; empty string = "uncategorized", absent = all) and are updated with `navigateTo`, so deep links, back/forward and SSR filtering work for free and no refetch occurs. Ephemeral, feedback-only query params that the legacy page generated itself in its own redirects (e.g. `?type=`, `?message=`, `?upgrade=1`) are dropped rather than ported. Confidence: 0.55
